CTScts.mjs · receita-change-request.md · receita-brfplus.md

A change request como raio-X — e o diff contra o sistema.

Duas vias que não veem a mesma coisa: o ADT consolida e enriquece; as tabelas E070/E071/E071K são as únicas com as entradas de CHAVE. anatomia cruza as duas.

TABKEY fatiado

{ fatiar: true } corta a chave concatenada pelo layout do dicionário (DDIF_FIELDINFO_GET): 300D1411Z0 vira { MANDT, SPRAS, WERKS, SOBSL } — e lerLinhaDaChave relê a linha para provar o corte.

diff TR × sistema

Por entrada: TADIR (existe), VRSD (versão numerada posterior = alterado), E071 da família (em edição agora), changedAt convertido pelo fuso da TTZCU. Vereditos: igual · alterado-depois · em-edicao · noutra-tr-depois · inexistente · por-chave.

Anatomia de BRF+

Tipo sem coleção ADT se revela pela TR: catálogo FDT_ADMN_0000 (app real: 76 objetos), duas vias de transporte, e o custom que não passa pela TADIR.

Medido no s4h 758.Versão numerada só nasce quando o conteúdo muda — transporte de cópias re-carimba o ponteiro sem provar alteração; a leitura do CTS é stateless (sessão órfã derruba o ADT stateful).

O agente executa ABAP e lê o console.

Uma classe que implementa if_oo_adt_classrun; o body da resposta é a saída de out->write. ~80 ms no S4H.

runClass

Executa uma classe já ativa. Com novaSessao: true abre sessão limpa antes de rodar.

deployAndRun

Cria, ativa e executa em sessão nova, numa chamada. É o driver de POC: monta BDCDATA, chama a transação, devolve a BDCMSGCOLL como JSON.

HTTP 200 não é sucesso.Erro de execução vem com status 200 e a mensagem no body. A lib interpreta o body, não o status.
O load antigo fica preso à sessão que fez o deploy.Causa-raiz medida: a mesma sessão stateful devolve a classe velha indefinidamente; uma sessão nova executa a versão nova de primeira. deployAndRun já faz isso sozinho.

segurança

Guard-rails no código, não em documento.

Regras inegociáveis que a lib aplica antes de a requisição sair da máquina.

assertZYSó objetos Z/Y são criados, alterados ou apagados. Qualquer outro nome é recusado.
assertReadOnlydataPreview aceita só SELECT/WITH e recusa INSERT, UPDATE, DELETE, MODIFY, DROP, CALL…
deleteObjectExige objeto Z/Y e confirm: true — irreversível, sem atalho.
unlockSempre em try/finally. Nenhum objeto fica travado por erro no meio do caminho.
activateSempre em sessão nova — evita o load antigo preso à sessão stateful.
senhaPerguntada na hora, vive só em memória, nunca toca o disco. O cache guarda apenas cookie + token CSRF, com TTL de 30 min.
