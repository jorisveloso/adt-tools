# NOTA 3751960 — Campos "Start/End Service Provision Location" ausentes no DACTE

Fonte: `notas/NOTA_3751960_E_20260901.pdf` (extração manual da seção correta, 2026-09-01).
Exemplo de caso de teste v1 do sap-note — a nota já foi aplicada MANUALMENTE no SXD;
este arquivo documenta COMO validar por medição que ela está aplicada.

## Symptom
Campos "Start/End Service Provision Location" não aparecem no DACTE quando o layout
impresso é o configurado em `EDOC_BR_DACTE_OP`.

## Manual Activities (aplicação manual, JÁ FEITA no SXD)
1. SFP → form `EDOC_BR_DACTE_OP` → Utilities → Upload/Download.
2. Fazer upload do XDP (índice da nota) e salvar e ativar.

## O que prova que está aplicada (asserts de leitura)
O XDP em si não é comparável byte a byte sem o anexo da nota (o PDF baixado não tem
embfile — embfile_count = 0). Por isso o assert desta v1 é por EXISTÊNCIA/ESTADO/
ATIVIDADE do form e seu layout, lidos fora da LUW do SAP GUI:
- o form `EDOC_BR_DACTE_OP` existe no FPLAYOUT com STATE = A (ativo);
- há entrada no FPCONTEXT apontando para a interface;
- a interface existe no FPINTERFACE.

```asserts
[
  {
    "tipo": "adobe_form",
    "form": "EDOC_BR_DACTE_OP",
    "espera": { "exists": true, "active": true },
    "rotulo": "Form EDOC_BR_DACTE_OP existe e está ATIVO no FPLAYOUT"
  }
]
```

## Como rodar
```
node tools/notas.mjs validar 3751960 --sistema sxd
```
Conexão pela sessão cacheada da lib ou via SAP_SXD_USER / SAP_SXD_PASSWORD no `.env` / ambiente.
